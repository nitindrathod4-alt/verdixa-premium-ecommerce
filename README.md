# Verdixa Premium E-Commerce

Premium custom e-commerce experience for Verdixa — Botanical Wellness.

## Stack
- Next.js
- React
- TypeScript
- Framer Motion
- GSAP (planned for advanced scroll experiences)
- Supabase/PostgreSQL (integration phase)
- Razorpay (integration phase)
- Vercel

## Current milestone
Phase 1 foundation: premium responsive homepage, product collection, philosophy and ritual sections.

## Environment
Copy `.env.example` to `.env.local` and add credentials when backend integrations are implemented.

## Run
```bash
npm install
npm run dev
```
